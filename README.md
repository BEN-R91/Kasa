Kasa

Projet réalisé dans le cadre de ma formation OpenClassrooms.

Application web développée avec React permettant de consulter des logements à partir de données fournies dans le cadre du projet.

Fonctionnalités
Affichage d’une liste de logements
Navigation entre les différentes fiches
Gestion des composants React
Mise en place d’un carrousel d’images
Gestion des erreurs et des routes
Interface responsive
Technologies utilisées
React
JavaScript
Vite
HTML
CSS
Git / GitHub

Objectif du projet :
Mettre en pratique le développement d’une application React structurée, réutilisable et responsive.
